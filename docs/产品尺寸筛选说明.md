# 产品尺寸筛选功能说明

## 功能概述

分类页面的筛选功能可以根据产品的**长度**和**宽度**进行筛选，帮助用户快速找到符合尺寸要求的产品。

## 数据来源

筛选功能会自动从以下位置读取产品尺寸数据（按优先级）：

1. **`size` 字段**（优先）- 直接存储尺寸字符串
2. **`params` 数组**（备选）- 从参数列表中查找"规格"或"尺寸"参数

### 支持的 params 参数名称

系统会自动识别以下参数名称（不区分大小写）：
- `规格`、`规格（cm）`、`规格 （cm)`、`规格(cm)`
- `尺寸`、`尺寸（cm）`、`尺寸 （cm)`、`尺寸(cm)`
- `size`、`spec`

### 数据库示例

**方式1：使用 size 字段**
```json
{
  "_id": "classic1",
  "title": "原木经典桌面 120x60",
  "size": "120*60*5cm"
}
```

**方式2：使用 params 数组**
```json
{
  "_id": "classic1",
  "title": "原木经典桌面 200x80",
  "params": [
    {"name": "规格 （cm)", "value": "200*80*4.5"},
    {"name": "颜色", "value": "原木色"}
  ]
}
```

### 尺寸格式要求

`size` 字段必须按照以下格式填写：

| 格式 | 示例 | 说明 |
|------|------|------|
| `长*宽*高cm` | `120*60*5cm` | 长度120cm，宽度60cm，高度5cm |
| `长*宽cm` | `100*50cm` | 长度100cm，宽度50cm |
| `长×宽×高cm` | `120×60×5cm` | 使用×符号也可以 |
| `长x宽cm` | `100x50cm` | 使用小写x也可以 |

**重要说明：**
- 第一个数字 = **长度**（用于长度筛选）
- 第二个数字 = **宽度**（用于宽度筛选）
- 第三个数字 = 高度（可选，不参与筛选）
- 单位 `cm` 可以省略，但建议保留

## 当前筛选选项

### 长度筛选选项
| 选项 | 范围 |
|------|------|
| 50cm以下 | 0 - 50cm |
| 50-100cm | 50 - 100cm |
| 100-150cm | 100 - 150cm |
| 150cm以上 | 150cm+ |

### 宽度筛选选项

|------|------|
| 30cm以下 | 0 - 30cm |
| 30-60cm | 30 - 60cm |
| 60-90cm | 60 - 90cm |
| 90cm以上 | 90cm+ |

## 如何填写产品尺寸数据

### 方法1：通过云数据库控制台直接编辑

1. 登录微信云开发控制台
2. 进入 **数据库** → **products** 集合
3. 找到要编辑的产品记录
4. 添加或修改 `size` 字段

**示例数据：**
```json
{
  "_id": "classic1",
  "title": "原木经典桌面 120x60",
  "price": 2999,
  "size": "120*60*5cm",
  "categoryName": "cat_classic"
}
```

### 方法2：通过CSV批量导入

在CSV文件中添加 `规格` 或 `尺寸` 列：

| 产品ID | 产品名称 | 分类名称 | 规格 | 价格（元） |
|--------|----------|----------|------|------------|
| classic1 | 原木经典桌面 120x60 | 经典桌面款 | 120*60*5cm | 2999 |
| classic2 | 原木经典桌面 150x70 | 经典桌面款 | 150*70*5cm | 3999 |
| resin1 | 树脂美学桌面 | 树脂设计款 | 100*50*4cm | 4999 |

**CSV支持的尺寸字段名：**
- `规格`
- `尺寸`
- `size`
- `spec`

### 方法3：通过小程序管理后台

如果你的小程序有管理后台，在添加/编辑产品时填写尺寸字段。

## 注意事项

1. **没有size字段的产品不会出现在筛选结果中**
   - 如果产品没有填写size字段，当用户使用尺寸筛选时，该产品会被过滤掉

2. **格式必须正确**
   - 数字之间用 `*`、`×` 或 `x` 分隔
   - 至少需要两个数字（长度和宽度）

3. **单位处理**
   - 系统会自动去除 `cm`、`厘米` 等单位
   - 建议统一使用厘米作为单位

## 自定义筛选范围

如果需要修改筛选选项的范围，可以编辑以下文件：

**文件路径：** `pages/category/category.js`

```javascript
// 长度筛选选项
lengthOptions: [
  { min: 0, max: 50, label: '50cm以下' },
  { min: 50, max: 100, label: '50-100cm' },
  { min: 100, max: 150, label: '100-150cm' },
  { min: 150, max: Infinity, label: '150cm以上' }
],

// 宽度筛选选项
widthOptions: [
  { min: 0, max: 30, label: '30cm以下' },
  { min: 30, max: 60, label: '30-60cm' },
  { min: 60, max: 90, label: '60-90cm' },
  { min: 90, max: Infinity, label: '90cm以上' }
]
```

## 常见问题

**Q: 为什么筛选后没有产品显示？**
A: 检查产品是否填写了 `size` 字段，以及格式是否正确。

**Q: 可以同时筛选长度和宽度吗？**
A: 可以，系统支持组合筛选，产品必须同时满足所有筛选条件。

**Q: 搜索和筛选可以同时使用吗？**
A: 可以，搜索关键词和尺寸筛选可以组合使用。
